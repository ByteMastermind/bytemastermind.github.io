XSLeakScan

A research crawler for the master's thesis Empirical Assessment of Cross-Site Leaks in Modern Browsers at the Czech Technical University in Prague.

Why it visited your site

Cross-site leaks (XS-Leaks) let a malicious web page infer information about a visitor's state on another site. This study measures how common the defenses against such leaks are on popular websites. Sites are taken from a public ranking of popular domains.

What it does

  • Requests the homepage and, if found, one public login or account page.
  • Sends a small number of GET requests without cookies and compares how the page responds in same-site and cross-site contexts.
  • Loads the same pages in a Chromium browser like an ordinary visitor, and records security headers, page structure and cookie attributes.

What it does not do

  • It never logs in, fills in or submits forms, or solves CAPTCHAs.
  • It does not attempt any attack and does not target real users.
  • It stops scanning a site on rate limiting (HTTP 429) or a bot challenge.

How to recognise it

  • The User-Agent header contains XSLeakScan and a link to this page.
  • Requests carry a From header with the contact address below.

Data handling

Cookie values and URL query values are not stored in readable form. Results are published only in aggregate, and no personal data is collected.
